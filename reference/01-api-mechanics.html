Exam focus

The blueprint names only tool_use and end_turn. Continue on the first, terminate on the second. Never terminate on parsed prose, an iteration cap, or the presence of a text block.

Exam answer vs current product — know both

The Exam Guide states subagents are spawned via the Task tool and that allowedTools must include "Task". On the exam, answer Task.

In the shipping product the tool was renamed to Agent (Claude Code v2.1.63). Current SDKs emit "Agent" in tool_use blocks while still reporting "Task" in the system:init tools list — which is why both names appear in the docs. The exam was written against the earlier naming.

What a subagent inherits

Receives

  • Its own prompt (system prompt)
  • The Task/Agent tool's prompt string — the only channel from parent
  • Project CLAUDE.md
  • Its tool definitions

Does NOT receive

  • Parent conversation history
  • Parent tool results
  • Parent system prompt
  • Preloaded skills unless in skills

Consequence: everything a subagent needs must be written into its prompt explicitly. The parent gets back only the subagent's final message. TS 1.3
