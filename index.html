How the lessons are built

Every lesson teaches mechanism first — the real field names, the real behaviour, with the primary doc linked. The exam is scenario-based, so it rewards understanding tradeoffs over recalling features; you cannot reason about a tradeoff you do not understand mechanically. The quiz at the end exists to convert reading into retention.

Pace

Sixteen lessons plus two mocks over 15 days is a little over one lesson per day. Community consensus puts typical preparation at 4–6 weeks; your daily Claude Code experience is what makes 2–3 weeks realistic, chiefly by making Domain 3 cheap. If a lesson's quiz goes badly, slow down rather than pressing on — a domain you half-know is worth fewer marks than the time it cost.

Run this repo

Everything is static HTML — no build step, no dependencies, nothing to install.

  1. Clone it 
    git clone https://github.com/kumargaurav121/ccaf-certification-prep.git
cd ccaf-certification-prep
  2. Open index.html in any modern browser — double-click it, or from the terminal: 
    open index.html        # macOS
xdg-open index.html    # Linux
start index.html       # Windows
  3. Optional — serve it locally if your browser restricts file:// pages: 
    python3 -m http.server 8000
# then visit http://localhost:8000
  • Quiz and mock scores persist in your browser's local storage only — nothing is sent anywhere.
  • Each lesson's quiz reshuffles answer order on retry, so you can't pattern-match positions.
  • Dark mode follows your system setting automatically.
Ask me anything as you go. If a lesson explains what without explaining why it works that way, tell me and I'll go deeper. The exam rewards understanding tradeoffs, and you cannot weigh a tradeoff you have only memorised.
